FindIt Campus is a beginner-friendly campus lost and found portal. It gives students a clear place to report belongings, browse current listings, and help return items to their owners.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## Current features

- Responsive dashboard layout
- Lost, found, and returned summary cards
- Six seeded sample listings represented by JavaScript objects
- Live search across title, category, location, and description
- Combined status and category filters with empty-result messaging
- Functional report-item form with validation and success feedback
- Mark Lost and Found listings as Returned
- Persistent listings using browser localStorage
- Accessible report-item form with required fields and keyboard focus states
- Keyboard-friendly focus states and semantic HTML

The initial application is client-side only. It does not include authentication, a backend, or a shared database, so listings are stored only in the current browser.

## Run locally

No build tools or dependencies are required. Open `index.html` directly in a modern browser, or serve the folder with any simple local web server.
